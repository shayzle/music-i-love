# Music I Love · Shanisya Lahida

An interactive music page showcasing the albums that influence the way I work and create.

Live: https://shayzle.github.io/music-i-love/

---

## About

A single-page experience built with vanilla HTML, CSS, and React (via CDN).
Features a fan-style album carousel with smooth animations, swipe and scroll support, and direct Spotify links.

---

## Features

- Drag, scroll, or use arrow keys to navigate albums
- Click the center album to open it on Spotify
- Fully responsive, works on mobile and desktop
